# AI LifeOS

AI LifeOS is a comprehensive, AI-powered personal operating system. It combines goals, habits, daily planning, memory retention, document intelligence, and advanced analytics into a single cohesive dashboard, powered by a personalized LLM.

## Features
- **AI Chat & Memory:** Talk to an AI that remembers your preferences, goals, and history.
- **Goals & Habits:** Track long-term goals and build daily habits with streak tracking.
- **Daily Planner:** Organize your day and get an AI-generated daily review.
- **Document Intelligence:** Upload PDFs/Images, extract text, and chat with your documents using RAG.
- **Analytics & Reports:** View weekly productivity scores and automated performance reports.

## Tech Stack
- **Frontend:** React, Vite, Zustand, TailwindCSS, Framer Motion
- **Backend:** Node.js, Express, MongoDB Atlas, Mongoose
- **AI/LLM:** Groq (Llama 3), Google Gemini, ChromaDB (Vector Search)
